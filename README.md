Till Death or a Factory Reset: the funniest single line of wedding vows a robot couple could say, for the make.fun "One-Line Robot Wedding Vows" bounty. `main.ts` writes one 148-character vow to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> I take you to be my lawfully wedded co-processor, to have and to hold, in sickness and in low battery, till death — or a factory reset — do us part.

## Run it

```sh
node main.ts
```
